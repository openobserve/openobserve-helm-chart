{{- $fullname := include "otel-fleet-collector.fullname" . }}
{{- if eq (include "otel-fleet-collector.role" .) "agent" }}
The OpenObserve fleet collector is being rolled out as a DaemonSet ({{ $fullname }})
in namespace {{ .Release.Namespace }}.

Each pod enrols with OpenObserve over OpAMP at
  {{ include "otel-fleet-collector.opampEndpoint" . }}
and receives its collector configuration from the server. Within a minute the nodes
appear under Fleet management in the OpenObserve UI; assign a configuration there.

Check the rollout:

  kubectl -n {{ .Release.Namespace }} rollout status daemonset/{{ $fullname }}
  kubectl -n {{ .Release.Namespace }} logs daemonset/{{ $fullname }}

Supervisor state (the agent identity) lives on each node at {{ .Values.agent.storage.hostPath }};
delete that directory on a node to re-enrol it with a new instance id.
{{- else }}
The OpenObserve fleet gateway is being rolled out as a StatefulSet ({{ $fullname }},
{{ .Values.gateway.replicas }} replica(s)) in namespace {{ .Release.Namespace }}.

Each pod enrols with OpenObserve over OpAMP at
  {{ include "otel-fleet-collector.opampEndpoint" . }}
and receives its collector configuration from the server. Assign the gateway fleet a
configuration whose otlp receiver listens on 0.0.0.0:4317 / 0.0.0.0:4318.
{{- if .Values.gateway.service.enabled }}

Agents send OTLP to
  {{ $fullname }}.{{ .Release.Namespace }}.svc:4317 (gRPC)
  {{ $fullname }}.{{ .Release.Namespace }}.svc:4318 (HTTP)
{{- end }}

Check the rollout:

  kubectl -n {{ .Release.Namespace }} rollout status statefulset/{{ $fullname }}
  kubectl -n {{ .Release.Namespace }} logs statefulset/{{ $fullname }}
{{- if .Values.gateway.persistence.enabled }}

Supervisor state (the gateway identity) lives on one PersistentVolumeClaim per replica
(state-{{ $fullname }}-<n>); delete a claim to re-enrol that replica with a new instance id.
{{- else }}

WARNING: gateway.persistence.enabled is false. Supervisor state lives in an emptyDir, so
every rescheduled pod enrols as a new collector and the old one stays behind as offline.
{{- end }}
{{- if gt (int .Values.gateway.replicas) 1 }}

With {{ .Values.gateway.replicas }} replicas, bind k8s_cluster, k8s_events and k8sobjects to the
k8s_leader_elector extension so only one replica runs them. A prometheus receiver or
tail_sampling processor in the configuration runs on every replica: scraped samples are
duplicated and traces are sampled from partial spans.
{{- end }}
{{- end }}
